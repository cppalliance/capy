= Parallel Fetch
:page-mode: how-to

Running multiple operations concurrently with cpp:when_all[].

== What This Example Shows

* Using cpp:when_all[] to run tasks in parallel
* Structured bindings for results
* Error propagation in concurrent tasks

== Source Code

[source,cpp]
----
include::example$parallel-fetch/parallel_fetch.cpp[tag=full]
----

== Build

[source,cmake,role=external]
----
add_executable(parallel_fetch parallel_fetch.cpp)
target_link_libraries(parallel_fetch PRIVATE Boost::capy)
----

== Walkthrough

=== Basic when_all

[source,cpp]
----
include::example$parallel-fetch/parallel_fetch.cpp[tag=when_all_dashboard,indent=0]
----

cpp:when_all[] requires children returning cpp:io_result[], so plain tasks are wrapped. The result is `io_result<std::string, int, double>`, a single `ec` plus the flattened payloads in input order.

=== Void io_tasks

[source,cpp]
----
include::example$parallel-fetch/parallel_fetch.cpp[tag=when_all_void,indent=0]
----

cpp:io_task[io_task<>] children return cpp:io_result[io_result<>] (an error code, no payload). Check `std::get<0>(r)` to detect failure.

=== Error Propagation

[source,cpp]
----
include::example$parallel-fetch/parallel_fetch.cpp[tag=when_all_errors,indent=0]
----

I/O errors are reported via `ec` in the cpp:io_result[io_result]. Thrown exceptions are captured separately. Upon error, cancellation is requested and the first exception is rethrown after all tasks complete.
