= Buffer Composition

Composing buffer sequences without allocation for scatter/gather I/O.

== What You Will Learn

* Creating buffers from different sources
* Using `std::array<const_buffer, N>` and `std::array<mutable_buffer, N>` for scatter/gather I/O
* Zero-allocation buffer sequence patterns

* Completed xref:8.examples/8b.producer-consumer.adoc[Producer-Consumer]

== Walkthrough

=== Creating Buffers

[source,cpp]
----
include::example$buffer-composition/buffer_composition.cpp[tag=make_buffer,indent=0]
----

`make_buffer` creates buffer views from various sources. No data is copied—the buffers reference the original storage.

=== Two-Buffer Scatter/Gather

[source,cpp]
----
include::example$buffer-composition/buffer_composition.cpp[tag=two_buffer,indent=0]
----

Capy's buffer-sequence concepts accept any range of `const_buffer` or `mutable_buffer`, so `std::array<X, 2>` is a buffer sequence with no further wrapping required. Use `mutable_buffer` for receive paths.

=== Multi-Buffer Arrays

[source,cpp]
----
include::example$buffer-composition/buffer_composition.cpp[tag=multi_buffer,indent=0]
----

For more than two buffers, the same pattern works with a larger `std::array`. Buffer sequences support `buffer_size()` and `buffer_length()` for querying total bytes and buffer count.

=== Scatter/Gather I/O

[source,cpp]
----
include::example$snippets/8c_buffer_composition.cpp[tag=write_gather,indent=0]
----

When you write a buffer sequence, the OS receives all buffers in a single system call. This is *scatter/gather I/O*:

* No intermediate buffer allocation
* No copying data together
* Single syscall for multiple buffers
