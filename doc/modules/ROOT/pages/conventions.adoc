= Conventions
:page-mode: reference

While each tool in this library comes with its own header file, there is also an aggregate header:

[source,cpp]
----
include::example$snippets/conventions.cpp[tag=include_umbrella]
----

The aggregate header includes most of the library, so each translation unit that uses it compiles all of those headers.
Production code should include only the headers it needs.
The aggregate header is convenient for learning the library and for small experiments.

All declarations reside in namespace `boost::capy`. For brevity, unless otherwise specified,
the source code examples in this documentation assume the following:

[source,cpp]
----
include::example$snippets/conventions.cpp[tag=convention]
----

The examples deliberately leave some operation results and xref:glossary.adoc#structured-bindings[structured bindings] unused,
so that the surrounding prose can explain them.
If you copy them, expect unused-variable and unused-parameter warnings under `-Wall -Wextra`.
Do not build copied examples with `-Werror`.

The library serves three audiences: application developers, framework authors, and I/O library authors.
xref:index.adoc#protocol-anatomy[Protocol Anatomy] describes what each audience needs.
