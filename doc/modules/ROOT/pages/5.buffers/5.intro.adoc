= Buffer Sequences
:page-mode: explanation

Every I/O operation is ultimately about transferring bytes. A write moves the
bytes produced by your program into the outside world; a read moves bytes from
the outside world into your program. Buffer sequences describe the storage
within your program that those bytes are written from and read into. They are
designed with the following criteria in mind:

 * They should be compatible with data types used by native I/O systems.
 * They should enable fast transport (contiguous storage).
 * They should be easy to use from within your program.

== What This Section Covers

* xref:5.buffers/5a.contiguous-buffers.adoc[Contiguous Buffers] -- cpp:const_buffer[] and

* xref:5.buffers/5b.composite-buffers.adoc[Composite Buffers] -- the concepts
