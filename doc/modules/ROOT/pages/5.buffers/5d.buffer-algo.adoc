== Counting Bytes

cpp:buffer_size[] returns the total number of *bytes* across every buffer in a sequence:

[source,cpp]
----
include::example$snippets/5d_buffer_algo.cpp[tag=buffer_size_example,indent=0]
----


cpp:buffers_empty[] reports whether a sequence carries no data, 
either because it holds no buffers or because every buffer has size zero.
It is a shorthand for `buffer_size(bufseq) == 0`.

[source,cpp]
----
include::example$snippets/5d_buffer_algo.cpp[tag=buffer_empty_example,indent=0]
----

Capy allows passing zero-size buffers to read and write operations. 
This is to cover the situations where the size of the buffer is determined dynamically,
based on incoming messages. A protocol may require that a sender first communicates the size of a
message, and then the bytes of the message. 
In such protocols, having nothing to send may be correctly
represented by sending the number zero, followed by no bytes. 
This would translate into later using a zero-size buffer. 

[CAUTION]
====
The following two functions have similar names but return different values:

 * cpp:buffer_size[] -- number of bytes across the entire buffer sequence,
 * cpp:buffers_count[] -- number of contiguous buffers in the sequence.

A three-buffer sequence of 100 bytes each has a cpp:buffer_size[] of 300 and a cpp:buffers_count[] of 3.
====


== Copying Bytes

cpp:buffer_copy[] copies bytes from one buffer sequence to another and returns the number of bytes copied:

[source,cpp]
----
include::example$snippets/5d_buffer_algo.cpp[tag=buffer_copy_example,indent=0]
----

The number of copied bytes is the smaller byte count of the source and target buffer sequences:

[source,cpp]
----
include::example$snippets/5d_buffer_algo.cpp[tag=bigger_buffer_copy_example,indent=0]
----

You can additionally cap the number of copied bytes in the third function argument,
which is useful for protocols with size limits:

[source,cpp]
----
include::example$snippets/5d_buffer_algo.cpp[tag=buffer_copy_at_most,indent=0]
----

Source and target need not have the same shape:

[source,cpp]
----
include::example$snippets/5d_buffer_algo.cpp[tag=buffer_copy_cross,indent=0]
----

The algorithm fills target buffers in order, reading from source buffers as needed. It handles a source buffer spanning several targets, and the reverse.

Capy creates and manages buffer handles on your behalf, such as the descriptors a type-erased stream passes to the OS. Each is valid only for the window its API documents.
