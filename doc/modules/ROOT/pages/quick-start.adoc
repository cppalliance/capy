= Quick Start

This page gets you from zero to a working coroutine program in five minutes.

NOTE: Capy requires {cpp}20 with coroutine support.

== Minimal Example

Create a file `hello_coro.cpp`:

[source,cpp]
----
include::example$programs/quick_start_hello.cpp[tag=full]
----

== Build and Run

[source,bash]
----
# With GCC
g++ -std=c++20 -o hello_coro hello_coro.cpp -lcapy -pthread

# Run
./hello_coro
----

Expected output:

----
The answer is 42
----

== What Just Happened?

1. `answer()` creates a suspended coroutine that will return 42
2. `greet()` creates a suspended coroutine that will await `answer()`
3. `run_async(executor)(greet())` starts `greet()` on the pool's executor
4. `greet()` runs until it hits `co_await answer()`
5. `answer()` runs and returns 42
6. `greet()` resumes with the result and prints it
7. `greet()` completes, `pool.join()` returns, and `main()` exits

The key insight: both coroutines ran on the same executor because affinity
propagated automatically through the `co_await`.
